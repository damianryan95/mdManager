# Extras

This is a **second file inside a subfolder** (`guide/`), here to demonstrate:

- The **file tree** shows nested folders (expand `guide` in the sidebar).
- **Cross-file search** — searching **xylophone** finds `feature-tour.md`, while
  searching **marmalade** (below) finds *this* file.
- **Deep links** work for nested paths too — copy the link and reopen it.

> [!NOTE]
